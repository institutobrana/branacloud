📘 RESUMO DO PROJETO – SISTEMA DE PRECIFICAÇÃO

Python + PySide2 + Peewee + PyInstaller

🔹 VISÃO GERAL

Este projeto é um sistema desktop de precificação, desenvolvido em Python 3.10, utilizando PySide2 (Qt Designer) para a interface gráfica, Peewee ORM para persistência de dados e SQLite como banco local.

O sistema gerencia listas de materiais, custos, preços, relações e cálculos financeiros, servindo como base para análises de lucratividade e expansão futura (ex.: cenários, indicadores, gráficos).

O projeto está estruturado para funcionar tanto em ambiente Python quanto empacotado em executável (.exe) para Windows.

🔹 TECNOLOGIAS UTILIZADAS

Linguagem: Python 3.10.x

Interface gráfica: PySide2 (Qt for Python)

ORM: Peewee

Banco de dados: SQLite (dados.db)

Gráficos: Matplotlib

Empacotamento: PyInstaller

Sistema alvo: Windows 64-bit

def resource_path(relative_path):
    try:
        base_path = sys._MEIPASS
    except Exception:
        base_path = os.path.abspath(".")
    return os.path.join(base_path, relative_path)

🔹 PADRÃO OFICIAL DE SOLICITAÇÃO VISUAL

Quando eu solicitar:

Padronização de tela

isso deve significar que o ajuste precisa ser aplicado em todas as telas existentes no projeto, mantendo o título, a função e a identidade de cada tela, sem alterar regras de negócio.

Padronização de tela passa a ser o nome oficial e equivalente a:

Padronização visual dos painéis e botões do sistema

Esse pedido passa a incluir obrigatoriamente:

- Padronização dos painéis com cantos arredondados.
- Padronização dos botões de ação do sistema.
- Padronização dos ícones, alturas, larguras e espaçamentos dos botões.
- Manutenção do título original de cada tela.
- Cabeçalho superior no mesmo padrão visual da tela Ficha pessoal -, com fundo verde, título da tela e botão X dentro desse mesmo cabeçalho verde.
- Botão X (fechar) com comportamento padronizado.
- Ao passar o mouse sobre o botão X, a cor deve mudar para vermelho.
- Correção de qualquer sobreposição, duplicidade ou posicionamento incorreto do botão X.
- Correção de casos em que o botão X fique sobre outro bloco, faixa, painel ou componente.
- Uniformização visual entre telas principais, modais e painéis auxiliares.
- Preservação do conteúdo e do funcionamento atual de cada tela.

Referências visuais principais:

- Tela Tabela de materiais para proporção e padrão dos botões.
- Tela Ficha pessoal - para padrão do cabeçalho verde com título e botão X.
