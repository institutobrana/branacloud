# Frontend React - Ampliação do miolo sem coluna direita

## Objetivo da etapa

Abrir a largura útil do bloco principal do `Quadro de avisos`, remover o badge `BRANA CLOUD` da barra turquesa e manter o layout alinhado à esquerda, sem coluna direita.

## O que foi ajustado

- O badge da barra turquesa foi removido.
- O bloco principal recebeu largura útil maior.
- A saudação foi compactada um pouco mais.
- As barras de aviso ganharam largura visual maior e mais respiro horizontal interno.
- O layout continuou alinhado à esquerda e sem cards laterais.

## Restrições respeitadas

- A barra turquesa operacional foi preservada.
- As abas compactas foram preservadas.
- A saudação e as barras de aviso foram preservadas.
- Nenhuma coluna direita foi reintroduzida.
- Topbar, rail lateral e submenu lateral não foram alterados.
- Nenhuma API nova foi criada ou consumida.
- O backend, o frontend legado, o banco e as migrations não foram alterados.

## Resultado do build

- `cd frontend-react`
- `npm.cmd run build`
- Build concluído com sucesso.
